# I/O 스위처 웹

I/O 스위처(벽 스위치를 눌러주는 BLE 기기)를 브라우저에서 조작하는 비공식 웹앱입니다.

- 사용 주소: https://reangma.github.io/switcher_web/
- 화면 확인용 모의 모드: https://reangma.github.io/switcher_web/?mock=1
- 아이폰: App Store의 “Bluefy – Web BLE Browser” 앱으로 열기
- 안드로이드: Chrome으로 열기

통신 방식은 [david419kr/io-switcher-local](https://github.com/david419kr/io-switcher-local)의 Android 앱과
[PySwitcherIO](https://pypi.org/project/PySwitcherIO/) 0.0.7을 근거로 합니다.
